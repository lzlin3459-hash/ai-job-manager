# AI 求职管家（Doubao Skill）

> 在豆包（Doubao）内运行的「求职全流程自动化管家」技能：上传简历 → 识别求职意向 → 全国采集匹配岗位 → 沉淀飞书多维表格 → 匹配评分 → 输出求职简报。**无需独立部署、无需外部 AI 模型、无需写代码**——把技能装进豆包即可使用。

---

## 一、它能做什么

| 能力 | 说明 |
|---|---|
| 简历解析 | 读取知识库中的简历（PDF/Word），提取个人信息、工作经历、项目经历、技能标签、教育背景 |
| 求职意向识别 | 从简历识别核心求职意向（如：ToB 企业服务 / AI 解决方案销售 / 商务 BD），而非仅按技能标签匹配 |
| 岗位采集 | 按求职意向生成检索关键词，通过浏览器在 BOSS 直聘、猎聘、企业官方招聘官网（字节/腾讯/伊利/蒙牛等）采集岗位，**全国范围** |
| 岗位沉淀 | 采集结果回填飞书多维表格「岗位库」（16 字段），按「岗位名称+公司+城市」去重，超期岗位自动标记"已下架"，保持库内鲜活 |
| 匹配评分 | 以待投岗位逐一输出匹配度（0-100），先硬性条件过滤（经验/学历/薪资），再按**求职意向相关度**+能力标签匹配，方向不符岗位显著降权；每条给出"优势/差距"点评 |
| 文档生成 | ①行业与岗位综合分析 ②当前开放匹配岗位清单（红色标注≥80 与临期岗位）③优化版简历 ④STAR 版简历 |
| 简报推送 | 汇总《求职简报》输出为飞书云文档，并通过飞书消息提醒 |
| 投递追踪 | 「投递追踪」表看板联动状态流转：待投 → 已投 → 面试中 → 已拒/Offer |
| 定时运行 | 每 3 天自动刷岗、重算匹配、推送简报（可选） |

## 二、架构

```
┌─────────────────────────────────────────────┐
│                豆包（Doubao）                │
│  ┌───────────────┐    ┌──────────────────┐  │
│  │ AI求职管家技能  │    │  定时任务（可选）  │  │
│  │ SKILL.md 指令  │◄──►│  每3天自动运行    │  │
│  └───────┬───────┘    └──────────────────┘  │
│          │                                   │
│   简历(assets/) 浏览器采集(路径1)             │
└──────────┼──────────────────────────────────┘
           │
┌──────────▼──────────────────────────────────┐
│           飞书（个人/企业账号均可）             │
│  「豆包求职管家」多维表格 Base                 │
│  ├─ 岗位库：16字段 + 高匹配/临期动态视图        │
│  └─ 投递追踪：10字段 + 状态看板（kanban）      │
│  简报 → 飞书云文档 → 飞书消息提醒               │
└─────────────────────────────────────────────┘
```

**关键设计**
- **以求职意向为核心**：匹配逻辑 = 上传简历 → 识别求职意向 → 按意向从全国筛选对应企业/岗位；运营/内容/直播等方向不符岗位自动降权，不浪费投递精力。
- **采集路径可替换**：优先企业官方招聘官网（免登录、可溯源）；BOSS 直聘/猎聘需登录时由用户接管浏览器完成验证。
- **数据沉淀在飞书**：岗位库与投递追踪是长期资产，字段/视图/看板一次搭好，持续运营。

## 三、快速开始（5 步）

> 前提：豆包电脑客户端 + 一个飞书账号（个人版或企业版均可；个人版与企业版数据不互通，二选一使用）。

1. **创建技能**：在豆包工作台 → 创建技能 → 名称「AI 求职管家」，把 `skill/SKILL.md` 中的「核心指令」完整粘贴为技能指令（或用豆包的 skill-creator 导入）。
2. **上传简历**：把你的简历（PDF/Word）上传到技能的知识库/assets 目录（替换示例说明，见 `skill/assets/README.md`）。
3. **搭建飞书多维表格**：按 `feishu-base/README.md` 在你的飞书创建「豆包求职管家」Base，含「岗位库」「投递追踪」两表（字段清单与视图配置已给出，支持复制字段 JSON 快速建表）。
4. **授权飞书连接器**：在豆包中授权飞书连接器，使技能可读写你的多维表格、创建云文档、发送消息。
5. **运行**：对话中直接说"用 AI 求职管家，帮我跑一轮求职分析"，或配置每 3 天定时任务自动运行。

## 五、隐私与安全（重要）

- 仓库**不包含**任何真实简历、飞书 Base token、账号信息或采集到的岗位数据——所有个人数据都留在你自己的豆包与飞书里。
- 技能运行时，你的简历、岗位库、匹配度仅存在于你的飞书账号空间。
- 采集仅读取公开招聘信息（企业官网/招聘平台公开页面），不涉及任何爬虫对抗或账号自动化投递。
- 建议在 `.gitignore` 中加入 `*.pdf`、`*.docx` 等个人简历格式，防止误提交。
