# 飞书多维表格搭建指南

在**你自己的飞书账号**（个人版或企业版均可，二选一使用；个人版与企业版数据不互通）中，创建「豆包求职管家」多维表格 Base，含两张表：「岗位库」与「投递追踪」。

## 方式一：手动创建（推荐，5 分钟）

### 1. 新建 Base
飞书 → 云文档 → 新建 → 多维表格 → 命名为「豆包求职管家」。

### 2. 建表「岗位库」
新建数据表并重命名为「岗位库」，按 `../skill/references/job-tracker-tables.md` 中「表1：岗位库」的字段清单创建字段（字段名、类型严格一致）：

| 字段 | 类型 |
|---|---|
| 岗位名称 | 文本（主字段） |
| 公司 | 文本 |
| 行业板块 | 单选（食品企业 / 互联网企业 / 其他） |
| 城市 | 文本 |
| 薪资范围 | 文本 |
| 经验要求 | 文本 |
| 学历要求 | 文本 |
| 岗位链接 | 文本 |
| 发布日期 | 日期 |
| 截止日期 | 日期 |
| 关键词标签 | 多选 |
| 匹配度 | 数字 |
| 状态 | 单选（待投 / 已投 / 面试中 / 已拒 / 已下架） |
| 抓取日期 | 日期 |
| 剩余天数 | 公式 `DAYS([截止日期],TODAY())` |
| 备注 | 文本 |

> 字段 JSON 可直接参考 `岗位库-字段定义.json`（供会使用 API/CLI 的用户批量建表）。

**视图**：建 2 个持久视图
- 「高匹配岗位」：筛选 匹配度 ≥ 80
- 「临期岗位」：筛选 剩余天数 在 0 到 3 之间

### 3. 建表「投递追踪」
字段清单见 `../skill/references/job-tracker-tables.md` 中「表2：投递追踪」：

| 字段 | 类型 |
|---|---|
| 岗位名称 | 文本（主字段） |
| 公司 | 文本 |
| 行业板块 | 单选 |
| 城市 | 文本 |
| 岗位链接 | 文本 |
| 投递日期 | 日期 |
| 状态 | 单选（待投 / 已投 / 面试中 / 已拒 / Offer） |
| 匹配度 | 数字 |
| 面试时间 | 日期 |
| 反馈备注 | 文本 |

**视图**：建「投递看板」视图，类型选**看板**，按「状态」分组（五列：待投 / 已投 / 面试中 / 已拒 / Offer）。

### 4. 授权
在豆包中授权飞书连接器，使技能可读写该 Base、创建云文档、发送消息。

## 方式二：字段 JSON 导入

`岗位库-字段定义.json` 与 `投递追踪-字段定义.json` 为字段定义数组（主字段为第一项），可直接用于 lark-cli / API 建表，或作为手工创建的核对清单。
