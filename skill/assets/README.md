# 简历资产（assets）使用说明

本目录用于存放**用户本人的求职简历**（PDF / Word）。仓库中不包含任何真实简历文件。

## 使用方法

1. 在豆包中创建「AI 求职管家」技能后，进入技能的知识库 / 资源目录（对应本 `assets/` 目录）；
2. 上传你的简历文件，建议命名：`你的姓名-求职方向.pdf`（例如 `张三-ToB企业服务.pdf`）；
3. 技能运行时，第 1 步「简历解析」会自动读取该简历。

## 简历建议包含

- 个人信息：姓名、电话、邮箱、城市
- 求职意向：目标岗位方向（如：ToB 企业服务 / AI 解决方案销售 / 商务 BD）
- 教育背景：学校、专业、学历、毕业年份
- 工作/实习经历：公司、岗位、时间、职责与成果（有数字更佳）
- 项目与商业实践：独立成交金额、方案产出、协作过程
- 技能标签：工具（飞书、Python、SQL、API 等）、软技能（沟通、谈判、项目管理）

## 隐私提示

- 简历是个人敏感信息，仅存在于你的豆包知识库与飞书空间；
- 上传到 GitHub 前请确认 `assets/` 目录不包含任何真实简历（`.gitignore` 已默认排除 `*.pdf` / `*.docx`）。
